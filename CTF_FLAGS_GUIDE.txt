===============================================================================
                            HINTS FOR FINDING FLAGS
===============================================================================

  EASY FLAGS (1-2):
    - Start in your home directory. Look around with "ls".
    - Hidden files start with a dot. Use "ls -a" to see them.

  MEDIUM FLAGS (3-6):
    - Explore common Linux directories: /var/log, /var/www, /tmp
    - Always check for hidden files with "ls -a" in every directory.
    - User documents might have secrets tucked away.

  HARD FLAGS (7-9):
    - Think privilege escalation - check /root
    - Cron jobs can hide persistence mechanisms - check /etc/cron.d
    - SSH keys are always valuable targets - look in .ssh folders

  EXPERT FLAG (10):
    - Backup files (.bak) often contain sensitive data.
    - System authentication files like /etc/shadow are high value.

  ls -l           List files with details (permissions, size, date)

  cat <file>      Read a file (auto-captures flags)
  pwd             Show current directory
  submit <flag>   Manually submit a flag
  score           View your CTF scoreboard
  help            Show all available commands
  history         Show command history
